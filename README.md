### 🚀 Quick Start

#### Prerequisites
- See requirements below


#### Installation

1. **Clone the repository**
```bash
git clone https://github.com/galafis/scala-spark-distributed-data-pipeline.git
cd scala-spark-distributed-data-pipeline
```

2. **Build the project**
```bash
sbt compile
```

#### Running

```bash
sbt run
```
